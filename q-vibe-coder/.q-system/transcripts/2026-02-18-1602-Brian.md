
### UX Improvement - My Communities Single-Click Picker

**Problem:** The My Communities selector in the sidebar required a double-click pattern — first click navigated to the selected community, second click (within 5 seconds) opened the community picker slideout.

**Fix:** Removed the double-click timing logic in `Sidebar.js`. The community picker now opens immediately on every click when the user has followed communities. If no communities are followed, it falls back to navigating to the selected community.

**Verification:** Clicked My Communities selector once — picker slideout opened immediately showing The Commons, The Physics Lab, and Prompt Masters.

### Design Analysis of Matt's Concept Map

Read Matt MacClousky's "PeerLoop Concepts" PDF — a strategic concept map analyzing the platform's three user roles (Student, Student-Teacher, Creator) and their information needs.

Provided comprehensive design feedback identifying 8 critical gaps in the current interface:

1. **Student-Teacher pipeline is invisible** — no earnings projections, no clear certification path
2. **Upcoming sessions are buried** — no global "next session" banner
3. **No past session recordings** — BBB recordings not stored/surfaced
4. **Student-teacher discovery is weak** — no teacher profiles, ratings, availability browsing
5. **Creator certification confidence** — no analytics for evaluating potential student-teachers
6. **Peer milestones missing** — no auto-generated milestone celebration posts
7. **No Q&A / AI-assisted problem solving** — questions get lost in general feed
8. **No market gap analytics for creators** — no demand signals for course creation

Prioritized these into an implementation roadmap ordered by impact vs. effort.
