## Current Session Work

### 14:10 - Fixed File Picker Bug
- **Problem:** Clicking the drop zone in "Upload File" mode didn't open the native file picker
- **Root Cause:** `AddFileModal` was defined as an inner function component inside `CourseCurriculumSection`. Each render created a new component function, causing React to unmount/remount the modal and break the ref.
- **Solution:** Changed `<AddFileModal />` to `{AddFileModal()}` - invoking as a function instead of rendering as a component
- **File:** `src/components/CourseDetailView.js` (2 occurrences)

### 14:15 - Fixed Supabase RLS Policy Error
- **Problem:** "new row violates row level security policy" when uploading files
- **Solution:** Added RLS policy to `course_files` table via SQL Editor:
  ```sql
  CREATE POLICY "Allow all" ON course_files FOR ALL USING (true) WITH CHECK (true);
  ```

### 14:20 - Fixed Supabase Storage Bucket Policy
- **Problem:** Same RLS error persisted - storage bucket had 0 policies
- **Solution:** Created storage policies for `course-files` bucket via SQL Editor:
  ```sql
  CREATE POLICY "course-files-upload" ON storage.objects
  FOR INSERT WITH CHECK (bucket_id = 'course-files');

  CREATE POLICY "course-files-read" ON storage.objects
  FOR SELECT USING (bucket_id = 'course-files');

  CREATE POLICY "course-files-delete" ON storage.objects
  FOR DELETE USING (bucket_id = 'course-files');
  ```
