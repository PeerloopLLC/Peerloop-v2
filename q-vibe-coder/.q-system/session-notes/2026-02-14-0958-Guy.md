## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Hub as default view mode | Better organized UX for creator communities |
| 40px overlap for header/tab gap | Eliminates sub-pixel rendering gaps between siblings |
| Wide layout via Settings toggle | User choice; degrades gracefully below 1100px |
| CSS `:has()` for parent width | Cleanly widens main-content only when wide layout active |
| 1100px responsive breakpoint | Hides sidebar, reverts layout on smaller screens |
| Profile card in right sidebar | Frees vertical space for feed in wide mode |
