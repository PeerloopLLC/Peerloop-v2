## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Tabs inside blue gradient header | Matches mockup design; active tab background blends into content |
| Reuse classic feed code | User principle: "use code from the main site" |
| Sticky top: 45px | Breadcrumb bar occupies top 45px at z-index 200 |
| IntersectionObserver for stuck state | Lightweight detection without scroll listener overhead |
