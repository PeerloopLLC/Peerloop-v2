## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Edge function for uploads | Client-side Supabase anon key didn't have storage upload permissions - edge function uses service role |
| Visible native file input | Hidden input with JS trigger didn't work in Chrome - native input is more reliable |
| Max 30MB file size | BBB has presentation size limits |
| PDF and PowerPoint only | These are the formats BBB supports for presentations |

## Technical Details

### Supabase Storage Policy Added
```sql
CREATE POLICY "Public upload access"
ON storage.objects FOR INSERT TO public
WITH CHECK (bucket_id = 'session-files');
```

### Edge Function Deployed
- Function: `upload-session-file`
- Accepts: FormData with file and filename
- Returns: JSON with url, filename, name
- Uses service role key for storage access
