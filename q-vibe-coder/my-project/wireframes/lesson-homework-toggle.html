4. Data Model Changes

How the data structure needs to change

Before (Session Level)

sessions: [
  {
    number: 1,
    title: "Introduction to AI Tools",
    allowHomework: true,  // Session level
    modules: [
      { title: "What is AI", duration: 15 },
      { title: "AI Landscape", duration: 20 }
    ]
  }
]

After (Lesson Level)

sessions: [
  {
    number: 1,
    title: "Introduction to AI Tools",
    modules: [
      {
        title: "What is AI",
        duration: 15,
        allowHomework: true  // Lesson level
      },
      {
        title: "AI Landscape",
        duration: 20,
        allowHomework: false
      }
    ]
  }
]

homework_submissions table change:

-- Add lesson_index column (keep session_number for grouping)
ALTER TABLE homework_submissions ADD COLUMN lesson_index INTEGER;

-- lesson_index = index of the module within the session (0, 1, 2...)
