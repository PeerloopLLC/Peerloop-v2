PeerLoop Course Builder - Complete Wireframe

Overview: Builder Tabs

The course builder has 4 main sections accessed via tabs in the left panel:

Intro
Curriculum
Pricing
Settings
Tab Flow:
1. Intro - Course landing page for buyers (title, description, objectives, thumbnail)
2. Curriculum - Session/lesson structure from original builder
3. Pricing - Price and what's included (from original builder)
4. Settings - Category, tags, visibility, publish status

  • title - Course title
  • description - Short description

How the builder fields map to the course object in database.js:

{ // INTRO TAB id: 22, // auto-generated title: "AI Tools Overview", description: "Navigate the world of AI tools...", duration: "3 hours", level: "Beginner", thumbnailGradient: "linear-gradient(135deg, #667eea 0%, #764ba2 100%)", learningObjectives: [ "Understand the major categories of AI tools", "Navigate AI writing tools confidently", ... ], includes: [ "Full course access", "2 live 1-on-1 sessions", ... ], // CURRICULUM TAB sessions: { count: 2, duration: "90 min each", format: "Live 1-on-1 via video call", list: [ { number: 1, title: "Text & Code AI", modules: [...] }, { number: 2, title: "Visual AI", modules: [...] } ] }, curriculum: [ { session: 1, module: 1, title: "...", duration: "20 min", description: "..." }, ... ], // PRICING TAB price: "$249", pricingOptions: { content: true, community: true, sessions: false, certificate: true }, // SETTINGS TAB category: "AI Tools", tags: ["AI Tools", "ChatGPT", "Claude", ...], badge: "New", instructorId: 8, // auto-set to current user // AUTO-GENERATED rating: 0, // starts at 0 ratingCount: 0, students: 0 }

Implementation Approach

Option A: Add Intro Tab to Existing Builder
Extend the interactive HTML with a new "Intro" tab. Keep Curriculum and Pricing tabs as-is.
  • Add tab switching for 4 tabs: Intro, Curriculum, Pricing, Settings
  • Intro tab contains form fields for description, objectives, includes
  • Thumbnail picker with gradient presets
  • Dynamic list management for objectives and includes
Option B: Wizard Flow (Step by Step)
Guide creators through each section in order.
  • Step 1: Basic Info (title, description, thumbnail)
  • Step 2: Learning Objectives
  • Step 3: Curriculum (sessions & lessons)
  • Step 4: Pricing
  • Step 5: Settings & Publish
  • Progress bar at top
