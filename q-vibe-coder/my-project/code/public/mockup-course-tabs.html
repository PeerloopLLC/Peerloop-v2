My Courses Tab Design Options

Current Design (Reference)
The current tabs are subtle text with a thin underline. Hard to recognize as clickable tabs.
Active Courses (1)
Completed Courses (2)
Option A: Pill Tabs
Rounded pill buttons like the Discover category filters. Clear visual distinction between active/inactive. Familiar pattern from the app.
Option B: Segmented Control (iOS Style)
Clean iOS-style segmented control. The raised active state clearly shows which is selected. Modern and minimal.
Option C: Card Tabs with Icons
Larger touch targets with icons. Very obvious that these are clickable. The border highlight on active makes selection clear.
Option D: Bold Underline Tabs
Similar to current but with bolder text and thicker underline. Hover states make it clear they're interactive. Subtle but improved.
Option E: Button Group
Connected buttons that look like a toggle. Very obviously clickable. The filled active state is unmistakable.
Option F: Individual Buttons
Separate bordered buttons. Each looks distinctly clickable. Good for adding more options later.
Option G: Tabs with Status Dots
Keeps the current minimal style but adds color dots to indicate status. Green for active, gray for completed. Thicker underline on active.
